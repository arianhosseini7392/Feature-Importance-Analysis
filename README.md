# Feature Importance Analysis: Handcrafted Features vs. Deep Saliency in 3D Point Clouds

An exploratory analysis of the relationship between handcrafted geometric features and deep learning saliency scores in 3D point clouds.

**Academic context:** Computer Programming — University of Tehran
**Supervisor:** Dr. Hanieh Naderi

## Overview

Deep learning models can identify salient regions in 3D point clouds, but understanding which geometric properties influence their saliency predictions can help make their behavior more interpretable.

This project investigates the relationship between **14 handcrafted geometric features** and saliency scores generated by three deep learning architectures:

* PointNet
* PointNet++
* DGCNN

The objective is to determine which geometric properties best explain the saliency patterns produced by these models.

## Methodology

### 1. Data Preprocessing

Each point cloud contains 1,023 points. To focus on the most informative regions, the analysis selects the **150 most salient points** from each point cloud.

Feature normalization was not applied because the analysis focused on individual linear relationships, Pearson correlation, and coefficient of determination (\(R^2\)).

### 2. Feature Analysis

Fourteen handcrafted geometric features were compared against the saliency outputs of the deep learning models. These features describe geometric properties such as curvature, spatial coordinates, edge intensity, and distance from the centroid.

Linear regression was used to examine how well individual handcrafted features predict saliency scores.

### 3. Evaluation Metrics

Two metrics were used to assess the relationships:

* **Coefficient of determination (\(R^2\)):** Measures how much of the variance in the target saliency scores is explained by the linear regression model.
* **Pearson correlation coefficient (\(r\)):** Measures the strength and direction of the linear relationship between a handcrafted feature and a saliency score.

These metrics provide complementary perspectives on the association between geometric properties and deep learning saliency.

## Results

The analysis identified **distance from the centroid (\(f_{10}\))** as a consistently predictive handcrafted feature.

This finding suggests that the spatial relationship between a point and the point cloud's centroid may help explain which regions deep learning models consider salient.

The results also suggest that deep learning saliency is associated with interpretable geometric properties rather than being entirely arbitrary.

## Limitations and Future Work

This project primarily examines individual linear relationships between handcrafted features and saliency scores. As a result, it may not capture nonlinear relationships or interactions between multiple geometric properties.

Potential extensions include:

* Multivariate regression to evaluate combinations of handcrafted features.
* Nonlinear models to capture more complex relationships.
* Quantitative comparisons across architectures and additional point clouds.
* Further validation of whether centroid distance consistently predicts saliency across different datasets.

## Conclusion

This project explores the interpretability of deep learning saliency in 3D point clouds by relating model-generated saliency scores to handcrafted geometric features. The findings highlight distance from the centroid as a promising predictor and motivate further investigation into how geometric properties contribute to deep model behavior.
